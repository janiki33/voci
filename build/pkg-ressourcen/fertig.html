Voci ist installiert

Voci startet jetzt automatisch. Die Karte bleibt immer im Vordergrund – einfach neben die Arbeit legen.

Kurz zur Bedienung: Klick auf die Karte deckt die Übersetzung auf, C / V / B bewerten das Wort, M öffnet das Menü und F1 die Hilfe.

Updates holt Voci selbst: Sobald eine neue Fassung bereitliegt, erscheint ein Hinweis auf der Karte; U spielt sie ein.
